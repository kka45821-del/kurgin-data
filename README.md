# KURGIN Data

Общий репозиторий данных для MVP.

- `stones.csv` — общий каталог камней
- `upload_batches.csv` — партии загрузок
- `sold_stones.csv` — проданные камни
- `favorites.csv` — избранное
- `cart_items.csv` — корзина
- `reservations.csv` — резервы

Публичный сайт читает данные отсюда. Админка будет публиковать данные сюда.
